# CPP Module 04

> Subtype polymorphism, abstract classes and interfaces.

## What's inside

- Virtual functions and polymorphism
- Deep copy
- Abstract classes
- Interfaces: AMateria, Ice, Cure, Character, MateriaSource

## Usage

```bash
cd ex00      # pick an exercise (ex00, ex01, ...)
make
./<executable>
```
Each exercise has its own Makefile and is compiled with `c++ -Wall -Wextra -Werror -std=c++98`.
